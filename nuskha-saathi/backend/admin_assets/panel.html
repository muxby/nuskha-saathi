Backend tests

Quick checks run inside the server with no network calls and no cost. Live checks also send one test image to Gemini, one request to openFDA and one sentence to the Urdu voice.

Urdu voice

The voice that reads instructions aloud in the app. Choosing one applies to new audio straight away; audio already saved for an earlier scan keeps the voice it was made with.

The choice is saved in the backend database. Free hosting clears that database when the server restarts, and the voice then returns to the default. To change the default itself, set URDU_TTS_VOICE on the server to uzma, asad, gul or salman.

Wake and keep awake

Free hosting puts the backend to sleep when idle, so the first scan after a quiet period is slow. Ping it before a demo, or keep it awake while this tab stays open.

Service configuration

Configured means enabled in the environment. Use the live checks above to prove a provider actually answers.
